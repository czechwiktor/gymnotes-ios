# 🏋️ GymNotes — Workout Tracker (Web & iOS)

A lightweight, mobile-first application for planning and tracking strength workouts. Built with vanilla HTML, CSS, and JavaScript, and packaged into a native iOS application using Capacitor and an automated GitHub Actions CI/CD pipeline.

🔗 **Live Demo:** [Click here to try it in your browser](https://YOUR-USERNAME.github.io/gymnotes-ios/www/)

## ✨ Key Features
* **Workout Logging:** Real-time tracking of sets, reps, and weights.
* **Exercise Library & Schedules:** Create and manage custom workout routines and exercise databases.
* **100% Offline & Privacy-First:** All data is stored locally on the device (`localStorage`) with built-in JSON backup export and import.
* **Native iOS Experience:** Tailored for notched screens (`safe-area-inset` / Dynamic Island) with custom app icons and splash screens.

## 🛠️ Tech Stack & Tools
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Mobile Wrapper:** Capacitor (iOS)
* **CI/CD:** GitHub Actions (automated asset/icon generation and `.ipa` compilation on a cloud macOS runner on every push)
